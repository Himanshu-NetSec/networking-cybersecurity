# IP Addressing

An IP address is a unique address used to identify a device on a network.

## Types of IP Address

- IPv4
- IPv6

## IPv4

IPv4 uses a 32-bit address.

Example:
192.168.1.10

## IPv6

IPv6 uses a 128-bit address.

Example:
2001:db8::1

## Private IP

Private IP addresses are commonly used inside local networks.

Examples:
- 192.168.0.0/16
- 172.16.0.0/12
- 10.0.0.0/8

## Key Point

IP addressing helps devices identify and communicate with each other on a network.
