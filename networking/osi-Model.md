# OSI Model

The OSI (Open Systems Interconnection) Model is a 7-layer model used to understand how data travels through a network.

## 7 Layers of OSI Model

1. Application
2. Presentation
3. Session
4. Transport
5. Network
6. Data Link
7. Physical

## Important Protocols & Devices

| Layer | Example |
|---|---|
| Application | HTTP, DNS, FTP |
| Presentation | Encryption, Compression |
| Session | Session management |
| Transport | TCP, UDP |
| Network | IP, Router |
| Data Link | MAC, Switch |
| Physical | Cables, Signals |

## Key Point

OSI Model helps us understand, troubleshoot, and learn computer networks layer by layer.
